## طريقة الرفع على GitHub Pages

### 1. إنشاء مستودع جديد على GitHub
1. ادخل على [github.com](https://github.com) وسجل دخول
2. اضغط على زر **New** أو **+** ثم **New repository**
3. اسم المستودع: `mazen-law-office` (أو أي اسم تريده)
4. اجعله **Public**
5. لا تضع علامة على README
6. اضغط **Create repository**

### 2. رفع الملفات
افتح Terminal أو Git Bash واكتب الأوامر التالية بالترتيب:

```bash
# انتقل لمجلد الموقع
cd path/to/mazen-law-office

# تهيئة Git
git init

# إضافة جميع الملفات
git add .

# عمل Commit
git commit -m "أول رفع لموقع مكتب المحامي مازن عدوى"

# ربط المستودع (استبدل YOUR_USERNAME باسمك على GitHub)
git remote add origin https://github.com/YOUR_USERNAME/mazen-law-office.git

# رفع الملفات
git branch -M main
git push -u origin main
```

### 3. تفعيل GitHub Pages
1. ادخل على المستودع على GitHub
2. اضغط **Settings**
3. من القائمة الجانبية اختر **Pages**
4. تحت **Source** اختر **Deploy from a branch**
5. Branch: اختر **main** و **/(root)**
6. اضغط **Save**
7. انتظر دقيقة ثم الموقع هيشتغل على:
   `https://YOUR_USERNAME.github.io/mazen-law-office`
